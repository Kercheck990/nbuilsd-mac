# assets/gifts — картинки подарков

Сюда кладите свои изображения подарков.

## Требования
- Формат: `.png` или `.webp` (лучше с прозрачным фоном)
- Размер: квадрат, рекомендуется **512×512**
- Вес: до ~200 КБ на файл

## Как подключить
1. Положите файл сюда, назвав его по id предмета — например `nft_016.png`.
2. Откройте `lib/data/gifts/gift_assets.dart` и добавьте строку в `_registry`:

   ```dart
   'nft_016': 'nft_016.png',
   ```

3. Если предмета ещё нет в каталоге — добавьте его в
   `lib/data/mock/mock_data.dart` или в `server/db/seed.sql` (таблица `items`).

Папка целиком уже подключена в `pubspec.yaml`, поэтому достаточно перезапустить
`flutter run`. Если файла нет — карточка покажет 🎁-заглушку и не упадёт.
